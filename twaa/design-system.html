Twaa Design System v1.0

Foundations and components for the توّا customer app. Every value below is a CSS custom property in styles.css, so screens never hard-code colours or sizes.

1. Brand

Tagline: من هنا لك.. توّا · "Local roots. Closer days." The wordmark is heavy, rounded Arabic lettering in Aubergine with a Mandarin shadda (the "spark"). The rounded cream wave ribbon is the secondary motif used on bags, uniforms and app banners.

Usage: the logo is always used as the mark alone — never accompanied by the name in text. Vector paths live in TWAA.logo() and assets/logo.svg (a drawn approximation); paste the official paths from the brand package there. Minimum size 40px wide; clear space equal to the shadda height; mono version for single-colour print.

Usage rules

Do
  • Aubergine for structure: app bar, primary text emphasis, prices, active nav.
  • Mandarin for one thing per screen: the primary action, plus small signals (ETA chip, discount badge, active indicator).
  • Cream as the page background; white cards float on it.
  • Pair Cream text on Aubergine (contrast 12.6:1) and white on Mandarin only for text ≥ 14px bold.
Don't
  • Don't use Mandarin as a background for large areas or body text.
  • Don't put grey text on the cream background below 13px.
  • Don't introduce new hues for categories beyond the tinted tile palette in data.js.
  • Don't convey stock/status with colour alone — always pair with a label.

3. Typography

Display: Baloo Bhaijaan 2 (rounded, echoes the logo) for headings, prices, buttons and the wordmark. Body: Cairo for everything else. Both cover Arabic and Latin so language switching never changes the voice. Numbers always use tabular figures (.num).

Voice

Egyptian colloquial Arabic, warm and short. Say "هاتها توّا" not "قم بطلب المنتج". Errors are human: "حصلت مشكلة بسيطة. جرّب تاني." Never show raw codes to customers.

Fixed order, top to bottom: image tile (category-tinted, 1:1-ish) with discount badge top-start and favourite top-end → name (2 lines max) → unit/size → optional low-stock pill → price row: current price bold in Aubergine, old price struck-through beneath, quick-add trailing. Out-of-stock items dim the whole card with a label and hide ADD.

Category tile palette

Each category has a soft tint and a matching glyph colour; use the same pair everywhere the category appears (home grid, listing rail, product tiles, cart thumbnails).

Sticky cart bar & bottom navigation

The cart bar appears as soon as the first item is added and floats above the nav on every browsing screen (home, categories, listing, search, deals). It shows count, subtotal and a single action.

7. Accessibility & performance

  • Text contrast ≥ 4.5:1 on cream and white; Cream-on-Aubergine 12.6:1; white-on-Mandarin reserved for bold ≥ 14px.
  • Every icon-only control has an aria-label; toasts use aria-live="polite"; the PDP sheet is role="dialog".
  • Touch targets ≥ 44px including stepper halves; 8px minimum gaps between targets.
  • Reserved image space (fixed tile heights) prevents layout shift on slow networks. Product images should ship as WebP ≤ 40KB with a tinted placeholder.
  • Body text 15–16px; nothing below 11px; Cairo at 500+ for legibility on low-end Android.
  • Motion ≤ 320ms, transform/opacity only, disabled under prefers-reduced-motion.
